## Ctrl+C(KeyboardInterrupt): 메뉴에서 입력을 기다리는 중 SIGINT 보내기

timeout -s INT 1 은 1초 뒤 Ctrl+C와 같은 신호(SIGINT)를 보낸다. --preserve-status 는 프로그램의 실제 종료 코드를 그대로 돌려준다.

```console
$ sleep 3 | timeout --preserve-status -s INT 1 python3 main.py | tail -n 3; echo "종료 코드: ${PIPESTATUS[1]}"

⚠️ 입력이 중단되었습니다. 데이터를 저장하고 안전하게 종료합니다.
👋 프로그램을 종료합니다. 다음에 또 만나요!
종료 코드: 0
```
- ✅ Ctrl+C 후에도 종료 코드 0 (정상 종료)
