## 파일에 저장되었는지 확인

```console
$ python3 -c "import json; d=json.load(open('.demo/state.json', encoding='utf-8')); print(len(d['quizzes']), '개'); print(json.dumps(d['quizzes'][-1], ensure_ascii=False, indent=2))"
8 개
{
  "question": "영화 기생충의 감독은?",
  "choices": [
    "박찬욱",
    "봉준호",
    "김기덕",
    "이창동"
  ],
  "answer": 2,
  "hint": "칸 영화제 황금종려상 수상자"
}
```
