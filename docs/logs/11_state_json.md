## 기본 저장 위치: 프로젝트 루트의 state.json

```console
$ grep -n 'DEFAULT_STATE_PATH\|QUIZ_STATE_PATH' main.py
14:DEFAULT_STATE_PATH = os.path.join(PROJECT_ROOT, "state.json")
18:    # QUIZ_STATE_PATH: 실습 스크립트가 내 실제 기록(state.json)을 건드리지 않도록 다른 파일을 쓰게 할 때 사용
19:    state_path = os.environ.get("QUIZ_STATE_PATH") or DEFAULT_STATE_PATH
```

실습 스크립트는 QUIZ_STATE_PATH로 .demo/state.json을 쓰고, 평소 python3 main.py 실행은 루트의 state.json을 쓴다.
